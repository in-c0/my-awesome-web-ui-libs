# Contributing

Before submitting changes, install Bun, run `bun run build`, `bun run test`, and `bun run test:browser`.

Prefer a small, independently testable material component over another demonstration-only effect. For design changes include before/after desktop and mobile screenshots, reduced-motion screenshots, and accessibility notes.

Please disclose any copied graphics, templates, textures, or code and their relevant license. Avoid copying third-party implementations or unlicensed fonts.
