# @in-c0/paper-ui

Pre-release React primitives: paper materials, graphite handwriting, and quiet controls.

Build with `bun run build`; `dist` contains compiled ESM, declarations and CSS.

See the workspace [README](../../README.md) and [third-party notices](../../THIRD_PARTY_NOTICES.md).

Status: **experimental alpha available on npm** (`npm install @in-c0/paper-ui@alpha`). The first public version is `0.1.0-alpha.1`; use the explicit `@alpha` tag, not the default `latest` tag. Import `@in-c0/paper-ui/styles.css` once in your React entrypoint. This updated documentation will be packaged with the next release.
